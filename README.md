# mac-window-capture

Mac のウィンドウを 1 枚ずつ画像としてキャプチャするメニューバーアプリ。「操作 → 待機 → キャプチャ」を繰り返す連続キャプチャができる。

## 機能

- ウィンドウを一覧から選ぶか (アプリ名・タイトルでインクリメンタル検索)、画面上のウィンドウを直接クリックして選ぶ。他のウィンドウに隠れていても撮れる (最小化中は不可)
- 中身だけ切り出す: ボタンやツールバーを除いた本文の領域をアクセシビリティ API で自動検出する。プレビュー上のドラッグでも指定でき、アプリごとに記憶する
- 1 枚撮る: PNG で保存し、クリップボードにもコピーする
- 連続キャプチャ: 撮り方を選んで繰り返し撮る
  - スクロール / キー入力 / クリック: 対象ウィンドウを操作しながら撮る。画面が落ち着くのを待って撮り、変化しなくなったら自動で止まる
  - 一定間隔: 対象ウィンドウには触れずに n 秒ごとに撮る。変化がない回は保存しない
  - 出力は PNG、PDF のみ、PNG と PDF、1 枚につなげる
  - PDF には文字認識 (OCR) のテキストを埋め込める (既定でオン)。日本語と英語に対応し、検索・選択できる PDF になる
  - 1 枚につなげる: スクロールして撮った画像の重なりを取り除き、縦長 (左右なら横長) の PNG 1 枚にする。タイトルバーなどの固定部分は 1 回だけ入る (`Stitcher.swift`)

### 画面

- 上: プレビュー。クリックで操作位置、ドラッグで切り出し範囲を指定する (プレビューと設定の境目はドラッグで調整できる)
- 中: 撮り方・終了条件・保存の設定
- 下: 常に表示される操作バー。左に進み具合や結果、右に「1 枚撮る」「連続キャプチャ開始 / 停止」

| ショートカット | 操作 |
|---|---|
| ⌘↩ | 連続キャプチャ開始 |
| ⌘. / Esc | 停止 |
| ⌘⇧C | 1 枚撮る |

### 安全のための停止

対象ウィンドウを操作する撮り方 (スクロール・キー入力・クリック) の実行中に、ユーザーがキー入力・クリック・スクロールをすると自動で止まる。実行中は対象ウィンドウが最前面になるため、ほかの作業のつもりで打った文字が対象に入ってしまうのを防ぐ。アプリ自身が送るイベントには印をつけて区別している。

## 必要な環境

- macOS 14 以降
- Xcode (Swift 6.2 以降)

## ビルドと起動

```sh
scripts/build-app.sh              # ビルド → ~/Applications/WindowCapture.app にインストール → 起動し直す
scripts/build-app.sh --no-launch  # 起動はしない
swift test                        # テスト
```

画面収録とアクセシビリティの許可は「バンドル ID ＋ 署名」に紐づくので、一度許可すれば再ビルドしても有効なまま残る。そのためにスクリプトは次を守る。

- インストール先は常に `~/Applications/WindowCapture.app` の 1 か所。上書きでインストールし、同じバンドル ID のコピーを他の場所に残さない
- 署名には Apple Development 証明書だけを使う。証明書が無い・複数ある場合はエラーで止まり、アドホック署名には切り替えない（アドホック署名はビルドのたびに署名が変わり、許可が外れる）
- 署名の要件 (designated requirement) が前回から変わったら警告する

証明書が複数あるときは `CODESIGN_IDENTITY="Apple Development: ..."` で 1 つに固定する。`swift run` や Xcode から直接起動すると権限がターミナルや Xcode 側に付いてしまうので、権限が必要な動作確認はインストールしたアプリで行う。

### アイコン

元画像は `Support/Icon/AppIcon-source.png`。差し替えたら `scripts/make-icon.sh` を実行して `Support/Icon/AppIcon.icns` を作り直す。macOS 26 以降は標準の形 (1024px 中央の 824px 角丸四角) から外れたアイコンが灰色の台座に載せられるので、スクリプトで角丸四角を描き直し、元画像をその形に切り抜いている。

## 権限

| 権限 | 用途 |
|---|---|
| 画面収録 | ウィンドウのキャプチャ |
| アクセシビリティ | 連続キャプチャ中のスクロール・キー入力・クリック、ウィンドウを最前面に出す |

初回起動時にウィンドウ上部のバナーから許可する。許可が反映されないときは「再起動」を押す。

## 構成

| ファイル | 役割 |
|---|---|
| `WindowInfo.swift` | ScreenCaptureKit でのウィンドウ一覧取得 |
| `WindowCapturer.swift` | ウィンドウ単体のキャプチャ、画面が落ち着くまでの待機 |
| `FrameComparator.swift` | 縮小グレースケール画像でのフレーム比較 (変化検出) |
| `InputDriver.swift` | CGEvent によるスクロール・キー・クリックの送信、AX でのウィンドウ前面化 |
| `CaptureSession.swift` | 連続キャプチャのループ |
| `Exporter.swift` | PNG・PDF の書き出し、クリップボードへのコピー |

## 動作確認用の起動オプション

設定を保存せずに、ウィンドウの選択から連続キャプチャまでを自動で行う。

```sh
open ~/Applications/WindowCapture.app --args \
  --select-window "scroll-test" \
  --settings-json '{"action":"scroll","maxCount":5}' \
  --save-dir /tmp/wc-out --start-loop --stop-after 10
```

AX ツリーや中身の検出結果を書き出す調査用コマンドもある (`DebugCommands.swift` を参照)。
